# グランドライン図鑑

ワンピースの世界観と人物関係を、地図・相関図・年表で学べる非公式のファンサイトです。

## ご注意

- **非公式です。** 原作者・出版社・アニメ制作会社とは関係ありません。
- **最新話までのネタバレを含みます。** エッグヘッド編・エルバフ編の内容も載っています。
- **内容には誤りがありえます。** データは2026年半ば時点の知識をもとに書いたもので、原作との照合はまだ済んでいません。間違いを見つけたら Issue で教えてください。
- 公式の画像は使っていません。文章はすべて独自の要約です。

## できること

- **人物相関図**: 210人・575本の関係。物語の現在地を動かすと、その時点で読者が知っている関係だけが表示されます。
- **家系図**: モンキー・D家、シャーロット家など14家系。
- **世界地図**: 平面の模式図と地球儀。麦わらの一味の航路を再生できます。
- **勢力図**: 組織の入れ子構造、海賊と世界政府のピラミッド、四皇・七武海などの顔ぶれの変遷。
- **年表**: 約1000年前から現在までの115の出来事。
- **編**: 32編それぞれのあらすじ、初登場人物、戦い、懸賞金の更新。
- **謎・伏線**: 21の謎を「未解決・一部判明・解決済み」で整理。作中の事実だけを載せ、考察は含めていません。
- **図鑑**: 用語107件と悪魔の実112種(能力者の継承つき)。
- **データ**: 懸賞金の推移とランキング、戦績。

## 使い方

ビルドは不要です。`index.html` をブラウザで開けば動きます。D3.js とフォントを CDN から読み込むので、ネット接続が必要です。

## 構成

```
index.html        画面の骨組み
css/style.css     スタイル(ライト/ダーク対応)
js/core.js        データの索引、詳細パネル、検索、物語の現在地
js/*.js           各画面(相関図、地図、勢力図、年表など)
js/data/*.js      データ(人物、関係、勢力、場所、年表、用語、悪魔の実など)
tools/validate.js データの整合性チェック
```

データを直したら、次のコマンドで存在しないIDへの参照などがないか確認できます。

```bash
node tools/validate.js
```
